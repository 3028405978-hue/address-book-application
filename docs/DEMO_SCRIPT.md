# 运行视频与演示脚本

已提供真实浏览器自动化录屏：[video/demo.mp4](video/demo.mp4)。它记录真实 Waitress 服务的实际操作，不是生成式视频，没有配音；为便于阅读，导出时将原始录屏放慢至 0.5 倍速。服务器在录制前已启动，因此视频不包含终端启动过程；如老师要求从终端开始或个人讲解，按下面脚本补录。

## 已录内容

首页空状态 → 导入 sample_contacts.xlsx → 五位联系人首页 → 新增苏明远并添加两个电话 → 编辑增加第二邮箱和第二地址 → 完整详情 → 收藏与收藏列表 → 按第二邮箱搜索 → 下载 Excel → 重新导入显示六条重复跳过 → 取消删除 → 确认删除 → 手机页面与表单。

## 建议本人补录（3—5 分钟）

1. 打开 Windows 终端，运行 README 的虚拟环境和 python app.py，说明 127.0.0.1:5000 是本地服务。
2. 新浏览器打开首页。上传 sample_contacts.xlsx，展示成功 5 条。
3. 新增测试联系人，填写姓名、两个电话、邮箱、社交账号和地址，保存，展示反馈。
4. 编辑联系人，修改第一电话，删除一个旧电话，再增加第二邮箱与地址，保存并展示全部值。
5. 点击收藏，再进入收藏列表；取消收藏后验证移出。
6. 输入姓名、第二电话、第二邮箱分别搜索。
7. 点击导出，在 Excel 打开文件，展示独立列和 JSON 多值数组，收藏值为 True/False。
8. 用刚导出的文件导入，展示重复跳过；复制新行并修改姓名再导入，展示新增。
9. 删除测试联系人：先取消确认，再接受确认，验证反馈。
10. 重启服务确认原有联系人还在；运行 pytest 展示结果；展示本地 Git 历史与实际远程发布状态。

Windows 11 可以使用 Xbox Game Bar（Win+G）录制浏览器，或 OBS 录制浏览器与终端；不要录入令牌、账号密码和真实私人联系信息。录制后检查画面可读、流程完整、MP4 正常播放，再上传 CSDN 支持的视频平台并把实际链接加到博客。
