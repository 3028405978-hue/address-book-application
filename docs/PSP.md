## 三、PSP 时间分析

本项目计划总工时为 690 分钟，模拟实际工时为 710 分钟，比计划增加 20 分钟，偏差约为 2.9%。

从时间分配来看，Coding 和 Test 占据了主要工作量。通讯录虽然功能相对简单，但涉及 SQLite 数据持久化、多联系方式管理以及 Excel 导入导出，因此编码和测试需要较多时间。

Planning 和 Design 的模拟用时略低于计划，主要因为项目需求比较明确，使用 Flask 和 SQLite 可以较快完成基础架构设计。

Summary 阶段的模拟用时略高于计划，反映了 GitHub 提交、测试证据、截图、演示视频和博客整理等交付工作的复杂性。

## 四、项目完成情况

项目实现了以下主要功能：

1. 联系人的新增、查看、编辑、删除及搜索。
2. 联系人收藏、取消收藏和收藏筛选。
3. 每位联系人支持多条电话、邮箱、社交账号和地址。
4. Excel 文件导入导出及数据持久化。
5. 中文响应式网页和基本输入校验。

根据项目测试报告，49 项自动化测试全部通过，后端代码覆盖率达到 97%。项目代码、测试及相关文档已上传 GitHub，并配置了自动化测试流程。

通过本次 XP 编程实践，我进一步了解了软件开发从需求分析、设计、编码到测试和交付的完整流程。

PSP 时间分析表明，编码、测试和文档整理是本项目的主要工作内容。今后可以在项目初期更合理地安排测试与交付时间，提高开发效率。
